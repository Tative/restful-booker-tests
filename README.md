# Тестирование REST API restful-booker

Тестовое задание: проверка API https://restful-booker.herokuapp.com в Postman.

В репозитории: postman/postman_collection.json (коллекция с проверками во вкладке Tests), docs/test-cases.xlsx (тест-кейсы с результатами), docs/bug-reports.xlsx (баг-репорты).

Итоги: 62 тест-кейса, 35 пройдено, 27 упало, найдено 14 дефектов. В Collection Runner это 111 проверок, из них 36 красных: в негативных запросах на создание брони по две проверки (статус и то, что бронь не создалась). Дефектов меньше, чем упавших кейсов, потому что один дефект может ронять несколько кейсов. Ещё в коллекции 5 служебных запросов, они создают бронь для своей папки.

Теги в названиях запросов: [DOC] ожидание из документации, [REST] в документации не описано, ожидание по HTTP/REST. Красный тест значит, что сервис ведёт себя не так, как ожидается.
